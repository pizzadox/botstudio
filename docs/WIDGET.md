# Виджет чата для сайта `/w/[secret]`

Публичная страница-виджет, которую клиенты встраивают на свой сайт. Плавающая кнопка
в углу открывает чат с ботом; переписка попадает в инбокс студии как обычный диалог
с источником «Сайт» (web).

## Как получить код

1. Откройте вкладку **«Каналы»** у нужного бота.
2. Подключите (или создайте) канал типа **«Чат для сайта»** — токен не требуется.
3. Нажмите кнопку **«Код для сайта»** — в диалоге готовый сниппет и инструкция.
4. Секрет канала хранится в поле `Channel.secret` (это часть URL `/w/<secret>`);
   URL вебхука виджету не нужен.

## Сниппет

```html
<iframe
  src="https://<адрес-студии>/w/<secret>"
  style="position:fixed;right:16px;bottom:16px;width:400px;max-width:calc(100vw - 32px);height:560px;max-height:calc(100dvh - 32px);border:0;border-radius:16px;box-shadow:0 12px 40px rgba(0,0,0,.25);z-index:2147483000"
  title="Чат поддержки"></iframe>
```

- Вставлять **перед `</body>`** на всех страницах сайта.
- На десктопе чат открывается в окне **400×560** в правом нижнем углу;
  на мобильных — почти на весь экран (`max-width/max-height` от вьюпорта).
- Готовый сниппет с вашим адресом студии — в диалоге «Код для сайта» (кнопка «Копировать»).

## Лимиты (защита от спама)

| Ограничение | Значение |
|---|---|
| Сообщения с одного IP | 20 в минуту |
| Сообщения в один диалог | 10 в минуту |
| Опрос новых сообщений (GET) | 60 в минуту с одного IP |

Превышение → ответ **429**: в чате появляется системная строка и **кулдаун ввода
на 60 секунд** с обратным отсчётом; после окна лимит восстанавливается автоматически.

## Как определяется «тот же посетитель»

- При первом открытии виджет генерирует `visitorId` и сохраняет в `localStorage`
  браузера посетителя (ключ `bstudio.visitorId` — общий с демо-чатом студии).
- Один браузер = один диалог: даже если `conversationId` потерялся (чистка кэша
  сайта, переезд страницы), диалог восстанавливается по `visitorId`.
- Диалог демо-чата изолирован: виджет не может подключиться к переписке из
  мессенджеров или симулятора.

## Как переписка попадает в инбокс

1. Сообщение посетителя → `POST /api/webhook/demo/<secret>` (тот же движок,
   что у мессенджеров).
2. Создаётся/переиспользуется диалог с `source='web'` — он виден во вкладке
   **«Инбокс»** (контакт: «Гость», если посетитель не назвал имя).
3. Если бот передал оператора (`needsOperator`) — диалог подсвечивается
   «требует внимания», оператор отвечает прямо из студии.

## FAQ

**Посетитель видит «Не опубликован».** Бот не опубликован — опубликуйте его в
конструкторе (кнопка «Опубликовать»).

**Сменили секрет / удалили канал.** Старый URL `/w/<secret>` перестаёт работать
(404). Создайте новый канал и вставьте новый сниппет.

**Куда писать, если лимиты мешают (нагрузочное тестирование)?** Тестируйте с
одного IP не чаще лимитов выше либо обратитесь к администратору студии.

**Данные посетителя.** В localStorage хранится только случайный `visitorId` и id
диалога; куки и сторонние трекеры виджет не использует.
